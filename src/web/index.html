      About, help, and feedback

      Denigma reads Finale MUSX files and exports MusicXML, MNX, and EnigmaXML. This page is a static application: the server only supplies HTML, JavaScript, CSS, and WebAssembly.

      For conversion bugs, missing notation, or feature requests, visit the Denigma issue tracker. Diagnostic reports include versions, selected settings, and Denigma messages, but never the source file contents.
